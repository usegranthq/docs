Welcome to the official documentation for the UseGrant API. This guide will help you understand and use the various
endpoints and features provided by the UseGrant API.

The UseGrant API lets you interact with UseGrant services programmatically. You can create and manage projects and
clients, and generate short-lived tokens for authenticated requests. Our API is designed to be intuitive and easy to
use, with comprehensive examples and detailed descriptions of each endpoint.

We recommend starting with the authentication section to learn how to securely access the API. From there, you can explore the different endpoints and see how they can help you achieve your goals.

## Bearer Authentication

The UseGrant API employs Bearer tokens for authentication.
To generate a token, login to the dashboard and navigate to the settings page at `/settings/token`. Ensure that you store the token securely.

For subsequent requests, the client authenticates by including this token in the `Authorization` header of HTTP requests, prefixed with "Bearer".

Example:

```http
Authorization: Bearer usegrant_<token>
```

Note: The token you generate will have the format `usegrant_<token>`.
The `usegrant_` prefix is used to indicate that it is a UseGrant token and you can also use it to identify if the token is accidentally exposed.

If/When the token is expired, you will receive a `401 Unauthorized` response.

### Example

Here is an example of how to include the Bearer token in a `curl` request to create a project:

```bash
curl -X POST https://sdk.usegrant.com/v1/projects \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "My Project", "description": "A project for testing"}'
```
