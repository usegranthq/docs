useGrant is an open-source OpenID Connect provider built for machine-to-machine authentication.
Your services request short-lived access tokens using the OAuth 2.0 client credentials grant,
and exchange them with cloud providers and other systems that trust OpenID Connect, without storing long-lived secrets.

useGrant works in both directions:

- **Issue tokens.** Create providers on the fly through the API, each with its own issuer URL, signing keys and optional custom domain,
  so every provider operates as a fully isolated environment. Add clients to a provider and mint tokens for them on demand.
- **Validate tokens.** Create tenants that trust external identity providers such as GitHub Actions,
  and validate their tokens against policies you define.

Everything is available through the REST API and the [TypeScript SDK](/core/sdk).
Start with [API Authentication](/core/auth) to create an API key, then follow one of the [guides](/core/guides).
